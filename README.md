# TamagoToDo

TamagoToDo — приложение списка задач с 3D-питомцем-компаньоном. Приложение написано на Python и PySide6. Слева расположен список дел, справа — питомец, который меняет выражение в зависимости от настроения.

## Возможности

- Создание, редактирование, поиск и фильтрация задач.
- Возможность выставить дедлайн, напоминания.
- Встроенный таймер с настройкой времени работы и перерыва.
- Светлая и тёмная темы, русский и английский языки.
- Настройка имени питомца и фона.
- Вращение 3D-модели и реакции на нажатие мышью/дедлайны задач. При сворачивании приложения тамагочи продолжает оставаться на экране.
- Автоматическое сохранение данных, резервное копирование и восстановление.
